# QA 截止日期

有界探索性 QA 使用已安装 gstack 运行时中的 `bin/gstack-qa-deadline`。Browser Quick 保留其 30 秒限制;Browser Full/Regression 使用其 5-15 分钟探索窗口的 15 分钟最大值。Review/ship smoke 保留其 5 分钟或 12 探针限制,以先到者为准。工作流强制执行探针数量;帮助器强制执行经过的时间。必需的计划检查在 smoke 保护之外:使用相同的检查点序列和由调用者剩余截止日期限定的有限命令超时,在 smoke 之后运行它们。过期的调用者截止日期使检查未运行;永远不会重新启动 smoke 时钟来运行它们。Functional Full/Quick/Regression 没有默认的总探索截止日期;Quick 将范围限制为成功加上风险最高的更改边缘。调用者更严格的持续时间或绝对截止日期仍限制运行。独立的混合运行使用拥有的 `REPORT_DIR/browser` 和 `REPORT_DIR/functional` 目录用于它们的时钟和检查点,在 `REPORT_DIR` 处有一个最终报告。在启动它们的时钟之前创建这些目录。单表面运行和 review/ship smoke 将它们的时钟和检查点保留在 `REPORT_DIR`;固定的调用者路径优先。

## 命令接口

使用 Bun 运行帮助器。`FILE` 是调用拥有的、规范的探针目录中的 `deadline.json`;其父级必须已存在。在下面的 `GUARD` 和 `FILE` 的位置使用带引号的绝对路径。

```text
bun GUARD start FILE SECONDS [EARLIER_UTC]
bun GUARD status FILE
bun GUARD run FILE -- COMMAND ARGS...
```

`start` 在基线之前立即运行一次。它专门创建一个版本化的、只读的收据,并在提供时将所选持续时间限制为较早的调用者截止日期。它不替换现有文件。`status` 读取实际时钟。`run` 在启动之前再次检查相同的收据,然后监督命令剩余的时间。重放和最小化使用相同的截止日期;永远不要替换收据或重新启动计时器以完成更多工作。

参数直接传递,不进行 shell 求值。对于允许的脚本,子命令是 `bash -c 'script'`;将每个探针保留在该子项内,而不是在帮助器之后附加未受保护的命令。缺失或格式错误的状态、符号链接路径和不可用的进程包含会阻止调度。

子项的 stdout/stderr 仍然是其证据。Guard 拥有的行以 `QA_DEADLINE ` 开头,并包含单独的 JSON 簿记;不要将它们复制到检查点的观察到的程序 JSON 中。将被拒绝的下一个探针标记为未运行;保留其原始检查点而不是将其重写为观察。对于发出 JSON 的探针,`observed` 是解码的子项 JSON 本身,而不是 `child` 信封或结果和 guard 元数据的混合。对于其他输出,保留完整的子项文本。命令字段保留完整的外部命令,包括 guard 调用;guard 诊断和解释属于报告。

## 报告测量

配置的探针预算不是总会话持续时间。子项启动/完成收据测量受保护的命令跨度;调用之间的间隔不测量单个工具成本或建立另一个运行可以容纳多少探针。

`/qa-only` 在探测停止后加载其报告部分,并在写入之前检查保留的证据与每个重复的发现。其正在进行的报告将总会话经过时间标记为未测量:最终写入和清理尚未完成。初始章程和最终发现使用调用者相同的报告文件。学习笔记和自动记忆遵循相同的调用者授权的写入目的地。可选的测量间隔命名其实际开始/完成收据和排除的工作,包括以后的报告写入和清理;它不是已完成的会话测量。

## 退出和清理行为

- Guard 过期或超时返回 124。子项也可以独立返回 124;使用 guard 收据的事件和 `timedOut` 字段来区分这些情况。
- Guard 错误返回 2;缺少可执行文件返回 127。否则保留子项的状态。
- 在 Linux/macOS 上,清理涵盖命令的继承进程组。分离的或新会话后代在该保证之外,因此不支持分离的探针。使用 SIGKILL 强制终止 guard 本身也会阻止其 POSIX 清理处理程序运行。
- 在 Windows 上,专用的嵌套 Jobs 包含探针 worker 及其后代,包括其直接父级退出的子项。无法初始化此包含会阻止命令启动。
- 收据刷新发生在探针清理之后,可能需要长达五秒钟;阻塞或损坏的输出返回 2。此宽限期不会延长探针工作。

终止探针客户端不会撤消已被服务接受的请求或停止已运行的浏览器。保留任何已知的部分效果并报告不确定的完成情况,而不是假设取消意味着没有效果。报告写入可能在探索截止日期之后完成,但新探针可能不会启动。
